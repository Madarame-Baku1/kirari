### Breaking changes

#### Requires `@vortexlabs/kirari` 1.x

The `^0.1.0` peer range no longer applies, so upgrading only `@vortexlabs/kirari-react` fails with a peer dependency conflict.

**How to migrate**

1. Upgrade `@vortexlabs/kirari` and `@vortexlabs/kirari-react` in the same install.
2. No code changes are needed: `Code` and `useTokenStream` keep the same props and behavior.

```sh
npm install @vortexlabs/kirari@^1 @vortexlabs/kirari-react@^1
```
