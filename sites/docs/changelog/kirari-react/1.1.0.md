### Improvements

- `<Code>` accepts text children the way React renders text, so `<Code>let x = {count}</Code>` highlights the joined source. Numbers and bigints are kept, `null`, `undefined`, and booleans render nothing, and element children throw a `TypeError`. The new `CodeText` type describes the accepted children.

### Bug fixes

- `lines` and `highlightLines` no longer add an empty last line wrapper after a trailing newline.
