### Improvements

- JavaScript, JSX, TypeScript, and TSX handle multiline and parenthesized arrows, nested default parameters, typed bindings, and contextual method names.
- Batch and streaming output stay consistent while signatures, comments, and arrow operators are incomplete.

### Bug fixes

- Function names are no longer highlighted as ordinary variables. Declarations, generic signatures, quoted names, lambdas, and closures are recognized across the programming-language grammars.
