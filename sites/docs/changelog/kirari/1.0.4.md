### Bug fixes

- Long runs of short tokens in CSS, Makefile, TOML, YAML, and Markdown with embedded languages now tokenize in linear time instead of slowing down quadratically.
- An unclosed Markdown fence on a single line no longer backtracks over the whole line.
- YAML numbers, booleans, and nulls end before `#` only when whitespace precedes it, so `3#x` reads as one plain scalar.
- TOML numbers no longer split names such as `42n`.
