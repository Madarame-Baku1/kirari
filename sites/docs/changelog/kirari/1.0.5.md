### Improvements

- Streaming Python, JSX, TSX, and JSONC with `createTokenStream` now rescans only near the end of the source instead of retokenizing everything on every write. Streaming 8 KB one character at a time drops from about 5 seconds to 0.1 seconds for Python, and from about 13 seconds to 0.2 seconds for TSX.

### Bug fixes

- Python names before a colon, such as `ready` in `if ready:` or `count` in `count: int`, are no longer highlighted as functions when a later line assigns a lambda.
- Streamed JavaScript and TypeScript function names stay revisable while a slash on the last line could still start a regex literal.
- `renderDecorated` with `lines: true` no longer adds an empty last line wrapper after a trailing newline.
