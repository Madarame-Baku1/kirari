### Improvements

- The default bundle shrinks from about 6.1 KB to about 4.3 KB gzipped. Function definition highlighting for languages other than JavaScript now ships with those language definitions instead of the core scanner, so `highlight`, `tokenize`, and `@vortexlabs/kirari/core` no longer include it. Highlighting output is unchanged.
- Definitions can set a new optional `definitions(tokens)` callback that runs after tokenizing and can retype names as functions. Built-in definitions that highlight function definitions set it, and a copy made by spreading one keeps it even when renamed. A custom definition that only reuses a built-in name such as `'python'` no longer gets that highlighting; set `definitions: python.definitions` to keep it.
