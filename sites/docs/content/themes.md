# Themes

Pick from built-in themes like GitHub, Dracula, Nord, and Catppuccin.

Import one theme and add `class="kirari"` to your `<pre>`. Each file only sets fallback colors, so your own `--kirari-*` variables still win.

```ts
import '@vortexlabs/kirari/themes/github-dark.css'
```
